# Thư mục `src`

Nơi chứa mã nguồn Python của pipeline học máy: nạp dữ liệu, tạo đặc trưng, huấn luyện mô hình và đánh giá kết quả.

## Các tệp hiện có

- `__init__.py`: đánh dấu `src` là một Python package.
- `data_loader.py`: dự kiến phụ trách đọc và tiền xử lý dữ liệu.
- `features.py`: dự kiến phụ trách tạo và biến đổi đặc trưng.
- `models.py`: dự kiến định nghĩa và huấn luyện các mô hình.
- `evaluate.py`: dự kiến tính các chỉ số đánh giá như MAE, RMSE và R².

Hiện các tệp Python chỉ có dòng chú thích mô tả module; chưa có phần triển khai chức năng.
