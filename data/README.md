# Thư mục `data`

Thư mục này lưu dữ liệu đầu vào và dữ liệu đã qua xử lý cho đồ án dự đoán chất lượng không khí.

## Thư mục con

- [`raw/`](raw/README.md): dữ liệu gốc, chưa qua xử lý.
- [`processed/`](processed/README.md): dữ liệu đã làm sạch hoặc biến đổi để phân tích và huấn luyện mô hình.

Hiện tại hai thư mục con chỉ có `.gitkeep`; chưa có tệp dữ liệu được thêm vào kho mã nguồn.
