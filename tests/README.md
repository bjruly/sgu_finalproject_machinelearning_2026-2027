# Thư mục `tests`

Nơi chứa kiểm thử tự động cho các thành phần xử lý dữ liệu, tạo đặc trưng, mô hình và luồng tích hợp. Dự án sử dụng pytest.

## Các tệp hiện có

- `__init__.py`: đánh dấu `tests` là một Python package.
- `test_data_pipeline.py`: dự kiến kiểm thử pipeline dữ liệu.
- `test_feature_engineering.py`: dự kiến kiểm thử việc tạo và biến đổi đặc trưng.
- `test_integration.py`: dự kiến kiểm thử luồng tích hợp từ dữ liệu đến kết quả.
- `test_models_performance.py`: dự kiến kiểm tra các điều kiện hiệu năng cơ bản của mô hình.

Hiện các tệp kiểm thử chỉ có chú thích mô tả; chưa có test case được triển khai.
