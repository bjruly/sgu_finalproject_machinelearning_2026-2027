# Thư mục `outputs`

Nơi lưu các sản phẩm được tạo ra trong quá trình phân tích, huấn luyện và kiểm thử, không phải mã nguồn đầu vào.

## Thư mục con

- [`figures/`](figures/README.md): biểu đồ và hình ảnh trực quan hóa.
- [`test_reports/`](test_reports/README.md): báo cáo kết quả kiểm thử.

Hiện các thư mục con chỉ có `.gitkeep`; chưa có kết quả được sinh ra.
